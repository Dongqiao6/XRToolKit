# 遥操作链路失联是一级安全观察

Quest 桥以固定频率发心跳；supervisor 超过 300 ms 收不到心跳就把链路失联当成 L2，同时停双臂和底盘。各执行节点仍有本地看门狗：底盘 200 ms 没有新 Twist 就持续发零速；臂 200 ms 没有新 target 且处于 gripped 就强制松开离合并 HOLD。心跳负责“整个遥操作链路断了”，本地看门狗负责 DDS/进程级故障。

## Considered Options

- 只做本地看门狗：各节点各自停，supervisor 不知道链路断了，无法统一锁存与审计。
- 依赖控制器超时：AMR 会保留最后速度，臂的行为依赖伺服超时，失效方向不确定。

## Consequences

- supervisor 多一个观察源 `TeleopHeartbeat`；桥进程必须独立于控制节点，挂掉时心跳自然消失。
- 心跳超时和相机观察超时是两条独立的 L2 触发条件，都要记录原因。

# 底盘与双臂独立同时遥操作，保护区随 JAKA base

底盘和双臂可以同时被遥操作，但两条链路各自跟随：左摇杆控底盘，Grip 控臂；保护区定义在 JAKA base 系，随底盘移动；相机异常时 L2 同时停双臂和底盘。底盘自身的碰撞安全仍由 AMR 的 lidar/bumper/急停兜底，相机不宣称 360° 覆盖。底盘 L2 用“阻断新速度 + 持续零速”，不用 `emergency_stop`；`move_pause` 只对 action 有效，第一版不依赖它。连续 5 次零速失败升级 `emergency_stop`。恢复要求摇杆回中并重新使能遥控。

## Considered Options

- 世界系协调：底盘移动时臂补偿以保持工具世界位姿；需要 AMR 定位、`T_world_base` 和臂补偿，是另一个控制项目。
- 只靠相机管底盘：顶置相机有后方/侧方盲区，不能替代 AMR 自带安全。
- 底盘 L2 直接 `emergency_stop`：恢复成本高，和相机占用的危险等级不匹配。

## Consequences

- 底盘移动时工具在世界系会随 base 平移；第一版不做补偿，操作者要为此负责。
- 必须限制底盘速度（尤其臂伸展时），并记录相机盲区。
- AMR 的 action / 充电 / 定位不纳入第一版安全门；第一版只做遥控、暂停/零速、状态与里程计。
- AMR 遥控链路没有速度 watchdog，最后一条速度会保留；零速必须由安全门持续重发。
- 手柄映射：X/A 保持左右夹爪锁定；系统软件急停 = 左摇杆按下（`LJ`，`Joy.buttons[6]`）；解除 = Y（`buttons[1]`）。
